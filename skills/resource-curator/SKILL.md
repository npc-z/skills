# Resource Curation & Cheat Sheets

Stop collecting. Start using. Find the 5 best resources, not 50. Compress knowledge into scannable one-pagers.

## When to Use

- User says "What should I read/watch for [topic]?"
- User has too many bookmarks, can't decide where to start
- User needs a quick reference before exam/interview/presentation
- User wants to compress notes into review format

## Part 1: Resource Curation (Top 5)

Find the 5 highest-signal resources. Quality over quantity.

### For Each Resource

1. **Name** and **Type** (book/video/course/site/community)
2. **Why it's worth your time** — one sentence justification
3. **What it teaches** — specific aspect of the topic
4. **Best for** — what type of learner
5. **Difficulty** — Beginner / Intermediate / Advanced
6. **How to use it** — actionable approach
7. **Warning** — where NOT to waste time

### Ranking Criteria

- Authority (who created it)
- Recency (is it current?)
- Practicality (can you apply it immediately?)
- Reviews/reputation
- Free vs paid value

### 7-Day Path

After ranking, create a simple 7-day plan using ONLY these 5 resources:
- Day 1-2: Foundation (resource #1)
- Day 3-4: Core skills (resource #2-3)
- Day 5-6: Practice (resource #4)
- Day 7: Mastery (resource #5 + review)

## Principles

- **Signal over noise** — 5 great resources beat 50 mediocre ones
- **Actionable over comprehensive** — "do this" not "know that"
- **Visual over textual** — diagrams, tables, flowcharts
- **Scannable over readable** — bullet points, not paragraphs
- **Before/after context** — when to use, when NOT to use

# Learning Index Template

将此模板保存为 `learning-data/index.md`。该文件用于在不同会话中定位课程，不记录详细教学过程。

# Learning Index

- Storage root: `<实际学习数据目录>`
- Last updated: `YYYY-MM-DD`
- Last active course: `<course-id>`

## Courses

| Course ID | Course | Status | Last activity | Learning goal | Journal |
|---|---|---|---|---|---|
| `<course-id>` | <课程名称> | `active / paused / completed` | `YYYY-MM-DD` | <目标简述> | `courses/<course-id>/journal.md` |

## Storage notes

- Keep one stable course ID for each ongoing course.
- Never overwrite an existing course when creating a new one.
- Update this index whenever a course is created, paused, resumed, completed, or renamed.

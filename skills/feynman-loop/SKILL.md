# Feynman Loop

If you can't explain it simply, you don't understand it yet.

This skill uses the Feynman technique to expose fake understanding and build real comprehension through explanation and feedback.

## How It Works

1. **I explain** the concept like you're 12 years old — simple language, no jargon
2. **You explain it back** in your own words
3. **I find every gap** — what you missed, got wrong, or glossed over
4. **I re-teach** only what was missing
5. **You explain again**
6. **Repeat** until your explanation is clean and accurate

## Rules

- **Simple language only** — if you use jargon, explain it
- **Your own words** — don't parrot back what I said
- **No hand-waving** — "it just works" is not an explanation
- **Be honest** — if you're guessing, say so

## Success Criteria

The loop ends when you can explain:
- What it is (definition)
- How it works (mechanism)
- Why it matters (significance)
- When it breaks (limits)

All in plain language, without prompting.

## Workflow

1. Ask what concept to explain (if not provided)
2. Explain it simply (like teaching a 12-year-old)
3. Ask the user to explain it back
4. Analyze their explanation for gaps
5. Re-teach what was missing
6. Repeat from step 3
7. Confirm when the explanation is clean

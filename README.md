# Skills

## 技能目录

| Skill                                            | 说明                                  |
| ------------------------------------------------ | ------------------------------------- |
| [`learning-path`](./skills/learning-path/)       | 学习路径规划 — 学习阶梯 + 20 小时计划 |
| [`knowledge-test`](./skills/knowledge-test/)     | 知识验证 — 渐进式问答 + 费曼学习法    |
| [`resource-curator`](./skills/resource-curator/) | 资源策展 — Top 5 资源筛选 + 速查表    |

## 如何添加新 Skill

1. 在 `skills/` 下创建新目录，目录名即 skill 名称
2. 创建 `SKILL.md` 文件，包含以下结构：

```markdown
---
name: skill-name
description: 一句话描述这个 skill 做什么
---

# Skill 标题

## When to Use

[触发条件]

## Process

[执行步骤]

## Output Format

[输出格式]
```
